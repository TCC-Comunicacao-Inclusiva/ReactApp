

## Dependências

### 🏗 Dependências principais
- **Expo**: `npm install --global expo-cli`
- **React Navigation**: `npm install @react-navigation/native`
- **React Native Screens**: `npm install react-native-screens`
- **React Native Safe Area Context**: `npm install react-native-safe-area-context`
- **React Native Vector Icons**: `npm install react-native-vector-icons`
- **React Native Gesture Handler**: `npm install react-native-gesture-handler`
- **React Native Reanimated**: `npm install react-native-reanimated`
- **React Native Async Storage** (Para salvar estados): `npm install @react-native-async-storage/async-storage`

## Comando para rodar o expo

Acessar o diretorio do projeto atraves do cmd e executar o comando:

npx expo start
